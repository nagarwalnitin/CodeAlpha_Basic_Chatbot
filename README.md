# 🎮 Hangman Game

A simple command-line Hangman Game developed in Python as part of my CodeAlpha Python Programming Internship.

## 📌 Features

- Random word selection
- User-friendly command-line interface
- Limited attempts
- Win/Lose conditions
- Input validation

## 🛠️ Technologies Used

- Python 3

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/nagarwalnitin/CodeAlpha_Hangman_Game.git
```

2. Open the project folder.

3. Run the program:

```bash
python hangman.py
```
