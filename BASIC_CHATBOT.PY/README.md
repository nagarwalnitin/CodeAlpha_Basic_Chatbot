# 🤖 Nexa AI Assistant

A simple Python chatbot developed as part of the CodeAlpha Python Programming Internship.

## 🚀 Features

- Greeting Responses
- Date, Time and Day
- Calculator
- Motivational Quotes
- Dice Roll
- Coin Flip
- Basic AI & Python Questions
- Help Command
- Chat History
- User Memory

## 🛠️ Technologies Used

- Python 3
- random module
- datetime module

## 📂 Project Structure

- main.py
- responses.py
- calculator.py
- memory.py

## ▶️ How to Run

```bash
python main.py
```
